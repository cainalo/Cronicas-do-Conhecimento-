"Morfossintaxe" é o estudo conjunto da **classe** de uma palavra (morfologia) e da **função** que ela exerce na frase (sintaxe). A mesma palavra pode mudar de classe conforme o uso, e a FCC explora isso: "o termo 'que' tem o mesmo valor em...", "a palavra 'como' introduz ideia de...".

### Classes × funções

| Classe (o que é) | Funções típicas (o que faz) |
|---|---|
| Substantivo | Sujeito, objeto, predicativo, aposto, núcleo de complemento |
| Adjetivo | Adjunto adnominal, predicativo |
| Advérbio | Adjunto adverbial |
| Verbo | Núcleo do predicado |
| Pronome | Substitui ou acompanha o substantivo |
| Preposição, conjunção | Conectam termos e orações (sem função sintática própria) |

Exemplos de **mudança de classe** (derivação imprópria):

- "O **olhar** do relator era severo." (verbo usado como substantivo)
- "Ele falou **alto**." (adjetivo usado como advérbio, invariável)
- "O **porquê** da decisão." (conjunção substantivada)

### Os valores de "que" e "se"

| "que" | Exemplo |
|---|---|
| Pronome relativo (retoma antecedente; troca-se por "o qual") | "O relatório **que** li..." |
| Conjunção integrante (inicia oração substantiva; troca-se por "isso") | "Sabe-se **que** houve dano." |
| Conjunção consecutiva (com "tão", "tanto") | "Era tão complexo **que** demorou." |
| Conjunção causal/explicativa | "Apresse-se, **que** o prazo acaba." |
| Partícula expletiva (pode ser retirada) | "Nós é **que** decidimos." |

| "se" | Exemplo |
|---|---|
| Pronome apassivador (voz passiva sintética, VTD) | "Analisaram-**se** as contas." |
| Índice de indeterminação do sujeito (VTI, VI, VL) | "Precisa-**se** de técnicos." |
| Pronome reflexivo | "O gestor **se** defendeu." |
| Conjunção condicional | "**Se** houver dano, haverá ressarcimento." |
| Conjunção integrante | "Perguntou **se** o prazo vencera." |

### Estrutura das palavras

| Elemento | Definição | Exemplo em "infraestruturas" |
|---|---|---|
| **Radical** | Base de significado | estrutur- |
| **Afixos** | Prefixo (antes) e sufixo (depois) | infra- (prefixo) |
| **Vogal temática** | Liga o radical às desinências | -a- |
| **Desinências** | Indicam gênero, número, pessoa, tempo | -s (plural) |

### Processos de formação

| Processo | Como ocorre | Exemplo |
|---|---|---|
| **Derivação prefixal** | Acrescenta prefixo | **in**constitucional, **re**analisar |
| **Derivação sufixal** | Acrescenta sufixo | fiscaliza**ção**, transparên**cia** |
| **Prefixal e sufixal** | Prefixo e sufixo independentes (a palavra existe sem um deles) | **des**leal**dade** |
| **Parassintética** | Prefixo e sufixo **simultâneos** (não existe a palavra só com um) | **en**tard**ecer**, **a**mold**ar**, **em**pobr**ecer** |
| **Regressiva** | Supressão de parte da palavra; forma substantivos a partir de verbos | debater → **debate**; combater → **combate**; buscar → **busca** |
| **Imprópria** | Mudança de classe sem alterar a forma | "o **sim** do conselho" |
| **Composição por justaposição** | Une palavras sem alteração fonética | passatempo, guarda-chuva, segunda-feira |
| **Composição por aglutinação** | Une com perda de fonemas | planalto (plano + alto), embora (em boa hora), fidalgo |
| **Hibridismo** | Elementos de línguas diferentes | auto**móvel** (grego + latim), sociologia |
| **Sigla / abreviação** | Redução | TCE, foto, pneu |

Distinção cobrada: em "desigualdade" há **prefixal e sufixal** (existe "desigual" e "igualdade"); em "entardecer" há **parassíntese** (não existem "entarde" nem "tardecer").

### Sinonímia e antonímia

- **Sinônimos** têm sentido igual ou próximo no contexto. Na prova, a pergunta é sempre sobre o sinônimo **no contexto**: "O conselheiro **ponderou** que..." aceita "observou" ou "considerou", mas não "pesou".
- **Antônimos** têm sentido oposto: **lícito** × **ilícito**, **prolixo** × **conciso**, **efêmero** × **duradouro**, **exíguo** × **amplo**.
- **Polissemia**: uma palavra com vários sentidos relacionados ("conta" bancária, "conta" de somar, "prestar contas").
- **Hiperônimo e hipônimo**: "documento" é hiperônimo de "ofício", "nota fiscal", "contrato". Usar o hiperônimo é um recurso de coesão para evitar repetição.

Vocabulário comum em textos de controle, com sinônimo contextual:

| Termo | Sinônimo no contexto |
|---|---|
| Elidir (a irregularidade) | Eliminar, afastar |
| Exíguo (prazo) | Curto, insuficiente |
| Óbice | Obstáculo, impedimento |
| Lídimo | Legítimo, autêntico |
| Mitigar | Atenuar, suavizar |
| Precípuo | Principal, essencial |
| Ínsito | Inerente, próprio |
| Corroborar | Confirmar, reforçar |

### Pegadinhas

1. "'Entardecer' e 'deslealdade' são formados pelo mesmo processo." Falso. O primeiro é parassintético; o segundo, prefixal e sufixal.
2. "'Combate' (de combater) é derivação regressiva." Verdadeiro. O substantivo nasce da redução do verbo.
3. "Em 'Sabe-se que houve dano', o 'que' é pronome relativo." Falso. É conjunção integrante; não retoma nenhum termo.
4. "'Planalto' é composição por aglutinação." Verdadeiro. Houve perda de fonema na junção.
5. "Sinônimo em prova se avalia fora do contexto, pelo dicionário." Falso. O sentido é sempre o do contexto da frase.
