Todo computador tem duas partes que trabalham juntas. Uma você pode tocar. A outra você só vê funcionando.

### Como hardware e software se separaram

Nos primeiros computadores eletrônicos, não havia essa separação tão clara.

- **ENIAC, 1946**: para fazer o ENIAC resolver outro problema, era preciso **mudar cabos e chaves à mão**. Trocar de tarefa podia levar dias. As instruções estavam, literalmente, nas conexões da máquina.
- **1945, programa armazenado**: um relatório de **John von Neumann** sobre o projeto EDVAC descreveu a ideia de guardar as **instruções na memória**, junto com os dados. Assim, trocar de tarefa passa a ser trocar o programa, sem mexer nos fios. Nasce a separação entre a **máquina** (hardware) e as **instruções** (software).
- **Cada vez mais lugar para guardar**: os dados passaram de **cartões perfurados** a **fitas magnéticas**; em **1956**, a IBM lançou o **RAMAC**, primeiro computador com **disco rígido**, que guardava cerca de 5 milhões de caracteres num móvel do tamanho de duas geladeiras. Depois vieram o **disquete** (a partir de 1971), o **CD**, o **pendrive** (por volta de 2000) e o **SSD**, sem partes móveis.

Hoje, um único SSD do tamanho de um chiclete guarda milhares de vezes mais que o RAMAC.

### Hardware: a parte física

**Hardware** é tudo o que é físico: a placa, o processador, os cabos, a tela, o teclado. Se cai no chão e quebra, é hardware.

As peças mais importantes:

- **Processador (CPU)**: executa as instruções, uma atrás da outra, muito rápido.
- **Memória RAM**: é a mesa de trabalho. Guarda o que está aberto agora. É rápida, mas **volátil**: quando o computador desliga, ela se apaga.
- **Armazenamento**: é o armário. Guarda arquivos mesmo com a máquina desligada. Pode ser um **HD** (disco que gira, mais antigo) ou um **SSD** (sem partes móveis, mais rápido).
- **Placa-mãe**: é a placa onde as outras peças se encaixam e conversam.

Comparação útil: a RAM é a mesa onde você abre o processo para ler. O armazenamento é o arquivo de aço onde o processo fica guardado. Mesa maior permite abrir mais coisas ao mesmo tempo. Armário maior permite guardar mais coisas.

### Software: a parte lógica

**Software** é o conjunto de instruções que diz ao hardware o que fazer. São os **programas**. Você não pega um software com a mão. Ele fica gravado no armazenamento e roda na memória.

Existem dois grandes grupos:

- **Software de sistema**: cuida da própria máquina. O principal é o **sistema operacional**, como Windows ou Linux.
- **Software aplicativo**: resolve uma tarefa sua. Editor de texto, planilha, navegador e aplicativo de banco são exemplos.

Exemplo: ao abrir uma planilha, o sistema operacional (sistema) pede ao processador e à memória (hardware) que executem o programa de planilha (aplicativo).

### Sem um, o outro não serve

Hardware sem software é uma caixa parada. Software sem hardware não tem onde rodar. Pense em um piano e uma partitura: o piano é o hardware, a partitura é o software. A música só acontece com os dois.

### Pegadinhas

1. "A memória RAM guarda os arquivos mesmo depois que o computador é desligado." Falso. A RAM é volátil; o que guarda depois de desligar é o armazenamento.
2. "O sistema operacional é um software." Verdadeiro. Ele é um software de sistema, que gerencia a máquina.
3. "O SSD é um tipo de software que acelera o computador." Falso. O SSD é uma peça física de armazenamento, portanto hardware.
