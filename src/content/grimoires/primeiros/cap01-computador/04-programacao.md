Todo programa nasce de uma lista de instruções. Escrever essa lista é **programar**.

### Como a programação surgiu

- **A palavra "algoritmo"** vem do nome do matemático persa **al-Khwarizmi**, que viveu no século IX e escreveu sobre como fazer contas passo a passo.
- **1843: o primeiro programa.** **Ada Lovelace** publicou instruções para a máquina analítica de Charles Babbage, que nunca foi terminada. É considerado o primeiro programa de computador.
- **Anos 1940: programar com números.** Os primeiros computadores só entendiam instruções em números, a chamada **linguagem de máquina**. Escrever um programa era lento e fácil de errar.
- **1947: o "bug".** A equipe do computador **Harvard Mark II** achou uma mariposa presa numa peça da máquina e colou o inseto no caderno de registros. O caso ajudou a popularizar a palavra **bug** (inseto, em inglês) para erro em computador.
- **1952: o tradutor automático.** **Grace Hopper** criou um dos primeiros **compiladores**, o A-0: um programa que traduz instruções escritas por pessoas para a linguagem de máquina.
- **1957: FORTRAN.** A IBM lançou o **FORTRAN**, uma das primeiras linguagens de programação muito usadas, em que se escrevia algo parecido com fórmulas de matemática.
- **Anos 1990: as linguagens de hoje.** O **Python** foi lançado em 1991; o **Java** e o **JavaScript**, em 1995. Elas são bem mais próximas da escrita humana do que os números dos anos 1940.

### Algoritmo: a receita

Um **algoritmo** é uma sequência de passos, em ordem, para resolver um problema. Uma receita de bolo é um algoritmo: misture, bata, despeje, asse por 40 minutos. Se você troca a ordem, o resultado muda.

Um bom algoritmo tem passos claros, ordem definida e um fim. "Asse até ficar bom" é vago. "Asse por 40 minutos" é claro.

Um **programa** é um algoritmo escrito em uma **linguagem de programação**, como Python, Java ou JavaScript.

### Variável: a caixinha com etiqueta

Uma **variável** é um espaço na memória com um nome, onde o programa guarda um valor. Pense em um pote com etiqueta "açúcar". O conteúdo pode mudar, mas a etiqueta continua a mesma.

Exemplo: `valor = 1500` guarda o número 1500 na variável chamada valor. Depois, `valor = valor + 100` muda o conteúdo para 1600.

### Condição: o "se"

Uma **condição** faz o programa escolher um caminho. A forma mais comum é **se... senão**.

Exemplo do dia a dia: se estiver chovendo, leve o guarda-chuva; senão, leve o boné.

Exemplo do Tribunal: se o valor do contrato for maior que o limite, marque para análise; senão, arquive.

### Repetição: o "enquanto" e o "para cada"

Uma **repetição** (ou **laço**) faz o programa repetir passos sem você escrever tudo de novo.

- **Para cada**: repete uma vez para cada item. "Para cada nota fiscal da pilha, confira o valor."
- **Enquanto**: repete enquanto uma condição for verdadeira. "Enquanto houver processos na fila, atenda o próximo."

Se a condição de um "enquanto" nunca ficar falsa, o laço não termina: é o **laço infinito**.

### Juntando tudo

Com variáveis, condições e repetições você já descreve muitas tarefas. Conferir mil notas fiscais e separar as acima de um valor é exatamente isso: um laço que passa por cada nota, uma condição que compara o valor e uma variável que conta quantas foram separadas.

### Pegadinhas

1. "Um algoritmo é uma sequência ordenada de passos para resolver um problema." Verdadeiro. É a definição básica, como uma receita.
2. "Uma variável guarda sempre o mesmo valor, que nunca pode mudar." Falso. O nome fica, mas o conteúdo pode ser trocado durante o programa.
3. "Um laço enquanto sempre termina sozinho, qualquer que seja a condição." Falso. Se a condição nunca ficar falsa, ele vira um laço infinito.
