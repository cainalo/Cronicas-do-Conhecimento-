# Game design

## Aprovado
Nada narrativo foi aprovado ainda. Títulos usados no app ("Torre", "O Códice das Sete Chaves", "Próxima missão") são provisórios.

## Mecânicas implementadas (técnicas, reversíveis)
- XP por estudo real, uma vez por conquista: 1º acerto de questão 10 · recuperar questão na revisão 5 · concluir lição 30 · ler capítulo inteiro 50. Repetir não dá XP de novo.
- Nível n a partir de 50·(n−1)² XP.
- Meta diária fixa de 10 questões (configurável no futuro).
- Sem vidas, sem punição por descanso.

## Premissa inicial (proposta, não aprovada)
Reino onde a confiabilidade dos registros sustenta tudo; o jogador é um aprendiz convocado por uma antiga ordem para recuperar conhecimentos. Ver `OPEN_QUESTIONS.md`.
