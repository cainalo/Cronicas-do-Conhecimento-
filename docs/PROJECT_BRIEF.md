# Visão do produto

**Crônicas do Conhecimento** (nome provisório) é uma plataforma de estudos gamificada para concursos públicos de TI que combina:
- a facilidade e as sessões curtas de apps como o Duolingo (sem copiar elementos exclusivos);
- a imersão de um RPG medieval original;
- uma biblioteca de **grimórios** — livros didáticos completos e aprofundados;
- preparação rigorosa para a banca e o formato real da prova.

**Público inicial:** o próprio autor, candidato a Técnico de Controle Externo — TI do TCE-GO (FCC, prova prevista para 17/01/2027).

**Escopo:** primeiro o TCE-GO; depois outros concursos de TI reutilizando o núcleo (conteúdo e configuração por concurso).

**Princípios:** aprender de verdade > parecer jogo; nada fictício apresentado como real; mobile-first; dados preservados; documentação para continuidade entre sessões.
