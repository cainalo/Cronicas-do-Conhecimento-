## Protocolo para uso das questões

1. Vincular toda questão real à prova e ao tipo/caderno exatos.
2. Não inferir resposta correta a partir de cursinho se houver gabarito definitivo oficial.
3. Checar anulação/alteração por recurso antes de liberar a questão.
4. Se o texto extraído do PDF tiver falhas, conferir a página visualmente e registrar revisão.
5. Identificar questões inéditas como “autoral — estilo da banca”; nunca atribuir falsa origem.
6. Respeitar direitos autorais e termos de uso. Para app público, avaliar se é permitido reproduzir o enunciado integral; quando não for, guardar metadados e linkar a fonte oficial.
